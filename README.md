I am a **Production Support & Cloud Engineer with 3+ years of real-world experience**
supporting **mission-critical healthcare and financial applications**.

My daily work is not tutorials — it is:
- Handling **P1/P2 incidents**
- Debugging **live production failures**
- Ensuring **high availability, security, and compliance**
- Working closely with **Dev, DevOps, QA, and Security teams**

I focus on **keeping systems running when things break**.

✔ Analyze logs using **CloudWatch, Kibana, Dynatrace**  
✔ Perform **Root Cause Analysis (RCA)** & preventive fixes

✔ Monitor systems using **Grafana & PagerDuty**

✔ Work in **ITIL environments (Incident, Problem, Change)**
